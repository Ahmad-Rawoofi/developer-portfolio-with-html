HTML Showcase

This section demonstrates the HTML features and web standards that are actually used in this portfolio.

  • Semantic HTML: Using meaningful HTML elements to give the page a clear structure.
  • Accessibility: Building the page so that its content and structure are easier to understand and navigate.
  • Forms: Using HTML form elements to collect user information in a structured way.
  • Form Validation: Using built-in HTML validation features to help ensure that submitted information follows the expected format.
  • Metadata: Using metadata to provide information about the document and support proper browser and search-engine processing.
  • Responsive Images: Using appropriate HTML image techniques to provide suitable images for different screen sizes and resolutions.
  • Web Standards: Following HTML standards and validating the document to identify structural and syntax problems.
  • SEO Basics: Using a meaningful document structure, headings, metadata, links and other HTML elements that help search engines understand the page.

Accessibility

Accessibility is an important part of how I build web pages. I aim to make my websites easier to understand, navigate and use for as many people as possible.

  • Semantic HTML: Using meaningful HTML elements to create a clear document structure.
  • Heading Structure: Using headings in a logical hierarchy to make the content easier to navigate.
  • Alternative Text: Providing meaningful alternative text for informative images.
  • Accessible Links: Using clear link text so users can understand where each link leads.
  • Accessible Forms: Connecting form controls with appropriate labels and instructions.
  • Keyboard Navigation: Making interactive elements usable through keyboard navigation.
  • Validation: Checking the HTML structure and fixing errors that could affect usability.

Developer Notes

This section documents some of the decisions I make while building this portfolio and explains why I chose a particular HTML structure.

  • Semantic Elements: I use meaningful HTML elements when they better describe the purpose of the content.
  • Document Structure: I organize content into a logical hierarchy so that the page is easier to understand and maintain.
  • Accessibility: I consider accessibility when choosing HTML elements, headings, links, images and form controls.
  • Validation: I use HTML validation to identify structural and syntax problems.
  • Continuous Improvement: I review my code and improve it instead of considering the first working version as the final version.
